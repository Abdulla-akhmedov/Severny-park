# Северный парк — каталог квартир

Учебный проект Ахмедова Абдуллы на WordPress: каталог квартир с фильтрами, сортировкой, галереями и избранным.

Посетитель выбирает количество комнат и диапазон цены, открывает подробности квартиры и сохраняет понравившиеся варианты. Администратор управляет квартирами и их характеристиками из WordPress.

## Что реализовано

- Пять демонстрационных квартир с собственными стилями интерьера.
- Подбор по количеству комнат, включая студии, и диапазону цены.
- Сортировка: сначала новые, дешевле, дороже, меньше по площади.
- Страница квартиры с галереей, описанием и таблицей характеристик.
- Избранное с добавлением, удалением, счётчиком и сохранением после обновления страницы.
- Общие шапка и подвал, отдельный шаблон главной.
- Адаптивная сетка: три, два или один столбец в зависимости от ширины окна.

## Стек

WordPress · PHP · JavaScript · CSS · MySQL · Gutenberg · Twenty Twenty-Five · Local · WP-CLI

Разработка велась в Local с PHP 8.2.29, nginx и MySQL 8.4.0. Репозиторий содержит собственный плагин и публичное наполнение проекта; WordPress и родительская тема устанавливаются отдельно.

## Запуск

Нужен отдельный свежий WordPress с PHP 8.2+ и WP-CLI. В Local открой **Site shell** у нового сайта.

1. Скопируй `plugin/severny-park` в `wp-content/plugins/` нового WordPress.
2. Установи и активируй Twenty Twenty-Five.
3. Активируй плагин и запусти импорт:

```bash
wp theme install twentytwentyfive --activate
wp plugin activate severny-park
wp eval-file /absolute/path/to/severny-park/scripts/import-demo.php --use-include
```

В последней команде укажи абсолютный путь к своей копии репозитория. Подробности: [SETUP.md](docs/SETUP.md).

После импорта доступны главная, `/apartments/` и `/избранное/`. Скрипт устанавливает публичное название сайта, главную страницу, структуру ссылок и пять шаблонов/частей шаблонов. Запускай его на отдельной демоустановке, поскольку эти настройки изменятся.

## Архитектура

Тип записи квартир — `sp_apartment`. Характеристики хранятся в метаполях:

| Поле | Значение |
| --- | --- |
| `sp_price` | Цена в рублях |
| `sp_area` | Площадь в м² |
| `sp_floor` | Этаж |
| `sp_rooms` | Комнаты; 0 — студия |

Фильтры используют параметры URL и изменяют основной запрос архива. Избранное хранит ID в `localStorage` под ключом `severny_park_favorites`. Страница избранного получает опубликованные квартиры через `/wp-json/severny-park/v1/favorites?ids=...`.

Шорткоды:

- `[sp_rooms_filter]` — фильтры на архиве квартир.
- `[sp_favorites]` — список сохранённых квартир на обычной странице.

Сохранение характеристик проверяет права, nonce и числовые значения. Серверный вывод экранируется. REST API избранного разрешает только чтение опубликованных квартир без пароля и ограничивает количество запрашиваемых ID.

## Границы проекта

- Исходная версия работает локально; публичный хостинг и домен пока не настроены.
- Избранное относится к одному браузеру и адресу сайта, без учётных записей и синхронизации.
- Избранное браузера не входит в резервную копию WordPress.
- Проверка узкой ширины окна выполнена; тестирование на физических мобильных устройствах остаётся следующим шагом.
- Полный ZIP Local, SQL, пользователи, пароли, журналы и локальная конфигурация в репозиторий не включены.
