# Обновление оформления «Северного парка»

Версия плагина: **0.2.0**. Предназначена для существующего сайта WordPress
«Северный парк» на теме Twenty Twenty-Five из этого репозитория.

## Что добавлено

- Светлый фон с мягкими зелёными градиентами, тёмно-зелёный первый экран
  с существующей визуализацией интерьера, новый футер и карточки квартир.
- Локальные шрифты Fira Sans: обычный, средний и полужирный. Файлы шрифтов
  входят в плагин; запросов к Google Fonts нет. Лицензия — в `assets/fonts/OFL.txt`.
- Сравнение двух или трёх квартир: цена, площадь, этаж, комнаты и цена за м².
  Выбор сохраняется в текущем браузере.
- Счётчик избранного в навигации, уведомления о добавлении и удалении.
- Кнопка избранного и стоимость за м² на странице отдельной квартиры.
- Увеличение фотографий с переключением стрелками и закрытием по Escape.
  Если изображение уже использует штатный lightbox WordPress, второй не добавляется.
- Фокус с клавиатуры, подписи кнопок, адаптивные сетки и учёт уменьшения анимации.

Каталог, фильтры, REST API и ключ существующего избранного
`severny_park_favorites` сохранены. Сравнение использует отдельный ключ
`severny_park_comparison_v1`. При недоступном localStorage сравнение работает
в памяти текущей страницы. Записи и метаполя в базе не изменяются.

## Сначала посмотреть оформление

В архиве плагина откройте `severny-park/demo/index.html` в обычном браузере.
Нужно распаковать всю папку: HTML использует CSS, JS, шрифты и изображения рядом.
В предпросмотре есть фильтры, избранное, сравнение и фотографии пяти учебных
квартир. При открытии через `file://` сохранение выбора зависит от настроек браузера.

Это отдельная страница для просмотра оформления. Она не заменяет WordPress,
не подключается к его базе и не переносит результаты выбора на работающий сайт.
Изображения — демонстрационные визуализации из исходного проекта.

## Установка на существующий сайт в Local

1. В Local откройте папку сайта через **Go to site folder**.
2. Сохраните копию папки `app/public/wp-content/plugins/severny-park`
   за пределами `wp-content/plugins`, чтобы можно было вернуть прежнюю версию.
3. Распакуйте архив и замените папку `severny-park` в
   `app/public/wp-content/plugins/` новой папкой с таким же именем.
   Внутри неё должны лежать `severny-park.php`, `experience.php`, CSS и JS.
4. Убедитесь в админке WordPress, что плагин «Северный парк» активен.
5. Обновите страницу с очисткой кеша: на Mac **Cmd + Shift + R**.

WordPress, тема, база данных и настройки Local из архива не заменяются.
При необходимости отката верните сохранённую папку плагина и обновите страницу.

Плагин добавляет оформление к существующим блокам. Первый экран распознаётся
по исходному заголовку «Найдите квартиру для вашей жизни» и цвету группы
`#f2f6f3`. Если главную страницу уже меняли, задайте нужной группе CSS-класс
`sp-home-hero` в редакторе блоков. Для изображения используется миниатюра
последней опубликованной квартиры без пароля; без миниатюры остаётся текстовый экран.

## Проверка после установки

- Главная: первый экран, навигация, три шага выбора; ширина телефона и компьютера.
- Каталог: фильтры по цене и комнатам, пустая выдача, переход на квартиру.
- Избранное: добавить, удалить, перезагрузить страницу; ранее сохранённые ID остаются.
- Сравнение: выбрать две квартиры, затем три; четвёртая не вытесняет уже выбранные.
  Проверить таблицу, удаление, очистку и ошибку загрузки без соединения.
- Квартира: исходное описание, фото и метаполя; увеличение фотографий,
  переключение стрелками, Escape и возврат фокуса на кнопку открытия.
- Проверить, что в консоли браузера нет ошибок, а адрес REST API не возвращает 404.

## Автоматические проверки

Workflow `.github/workflows/wordpress-checks.yml` проверяет PHP 8.2,
синтаксис JavaScript и логику сравнения. PHP-проверка использует настоящий
HTML Tag Processor из WordPress в репозитории и заглушки окружения:
защиту закрытого контента, расчёт цены, подключение ресурсов, первый экран
и сводку результатов каталога.

Локально: `node --test tests/experience.test.cjs`.
В окружении с PHP 8.2: `php tests/experience.php`.

Эти проверки не поднимают WordPress с MySQL и не проверяют визуальный результат
в браузере. Финальную совместимость с настройками конкретного сайта следует
проверить в Local по списку выше.
